Kết nối Google Firebase Cloud

Chế độ: Lưu trữ trình duyệt (LocalStorage)

Ứng dụng hiện lưu trữ dữ liệu tại máy của bạn. Để đồng bộ hóa tiến độ học trên các thiết bị khác nhau, hãy tạo một dự án cá nhân tại Firebase Console và điền thông tin dự án Web App của bạn dưới đây. Dữ liệu sẽ tự động đồng bộ thời gian thực!

Hướng dẫn kết nối Firebase

  1. Truy cập Firebase Console, nhấn Add project để tạo dự án mới.
  2. Vào mục Authentication, kích hoạt phương thức đăng nhập bằng Email/Password và Google.
  3. Vào mục Firestore Database, tạo một Database mới (chọn chế độ thử nghiệm test mode hoặc cấu hình rules cho phép đọc ghi).
  4. Ở phần cài đặt dự án (Project settings), kéo xuống dưới thêm một ứng dụng Web để lấy đoạn mã cấu hình (config object) chứa các thông số điền ở form bên cạnh.

Xuất / Nhập sao lưu cục bộ

Bạn có thể tải dữ liệu tiến trình học tập hiện tại về máy dưới dạng file JSON hoặc khôi phục từ file có sẵn.
